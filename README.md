# Wanderly Travel Agency Landing Page

A responsive travel agency landing page built with **HTML and CSS only**, as requested by the EZITECH task.

## Sections
- Responsive header/navigation
- Hero section with call-to-action
- Three travel destination features
- "Why Wanderly" feature section
- Contact call-to-action
- Footer

## Requirements covered
- No Bootstrap or CSS framework
- Responsive layout for desktop, tablet, and mobile
- No horizontal scrolling
- Semantic heading hierarchy: h1 → h2 → h3
- Accessible navigation button with ARIA attributes
- Meaningful text alternative for the logo link; decorative numeric icons use `aria-hidden`
- Clean HTML/CSS structure

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Technologies
- HTML5
- CSS3
- Small vanilla JavaScript snippet for the mobile menu

## Responsive Testing

The landing page was tested at the required viewport sizes:

- 375px — Mobile
- 1440px — Desktop

The layout adapts to both screen sizes without horizontal scrolling.
